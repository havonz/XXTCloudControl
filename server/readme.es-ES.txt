Si no existe un archivo de configuración, el servidor creará uno nuevo y se iniciará con una contraseña aleatoria.
La contraseña aleatoria se muestra una sola vez. Si la olvida, cámbiela con el siguiente comando:
./xxtcloudserver-<platform>-<arch> -set-password <password>

Ejemplo para Windows x64:
xxtcloudserver-windows-amd64.exe -set-password 12345678
