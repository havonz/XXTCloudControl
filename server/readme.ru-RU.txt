Если файл конфигурации отсутствует, сервер создаст новый файл и запустится со случайным паролем.
Случайный пароль отображается только один раз. Если вы его забыли, измените пароль следующей командой:
./xxtcloudserver-<platform>-<arch> -set-password <password>

Пример для Windows x64:
xxtcloudserver-windows-amd64.exe -set-password 12345678
