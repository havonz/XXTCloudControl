Wenn keine Konfigurationsdatei vorhanden ist, erstellt der Server eine neue Datei und startet mit einem zufälligen Passwort.
Das zufällige Passwort wird nur einmal angezeigt. Falls Sie es vergessen, ändern Sie es mit folgendem Befehl:
./xxtcloudserver-<platform>-<arch> -set-password <password>

Beispiel für Windows x64:
xxtcloudserver-windows-amd64.exe -set-password 12345678
