Se não houver um arquivo de configuração, o servidor criará um novo e será iniciado com uma senha aleatória.
A senha aleatória é exibida apenas uma vez. Se você esquecê-la, altere-a com o comando a seguir:
./xxtcloudserver-<platform>-<arch> -set-password <password>

Exemplo para Windows x64:
xxtcloudserver-windows-amd64.exe -set-password 12345678
